# 冒险村物语（Kairo Village）

开罗风格（开罗游戏 · Kairosoft）像素**等距 2.5D 村庄经营模拟**游戏。玩家打造冒险者村庄，建造各种建筑吸引冒险者，经营经济、培养职业、对抗怪物。

纯前端 Canvas 实现，无依赖、无框架，浏览器直接运行。

---

## 🎮 运行方式

本机起一个静态服务器即可（游戏用到 `fetch shadow_config.json`，需 HTTP 环境）：

```powershell
# 在项目目录下
python -m http.server 8090
# 或
npx http-server -p 8090
```

浏览器打开 → http://localhost:8090/index.html

> 版本缓存：改代码后请**强刷**（Ctrl+Shift+R）加载新版本。
> 控制台可见版本号：`console.log('[冒险村物语] 版本 v84')`，全局 `window.__VILLAGE_VERSION`。

## 🧩 项目结构

| 文件 | 作用 |
|---|---|
| `index.html` | 入口页面（含游戏画布 + 隐藏透视控制板） |
| `content.js` | **内容配置**：`BUILD_DEFS`（建筑）、`CLASS_DEFS`（职业/兵种）、`MONSTER_DEFS`（怪物）、`WEAPON_DEFS`（武器）、作物等 |
| `engine.js` | 引擎：等距投影、场景管理、实体工厂、网格←→屏幕换算 |
| `sprites.js` | **素材模块**：`IMG_SRC` 贴图注册、`SpriteKit`（底边贴地对齐 / 像素蒙版遮挡 / 形状阴影）、管线校验 |
| `game.js` | 主循环、玩法逻辑（经营/建造/战斗/怪物/AI）、渲染、存档 |
| `ui.js` | UI、建造菜单、属性面板、存档读档 |
| `shadow_strips.js` | 阴影条带数据 |
| `shadow_config.json` | 阴影配置（收缩/投影） |
| `assets/` | 全部透明 PNG 贴图 |
| `assets_raw/` | 生图源图（白底，被 gitignore） |

## 🛠️ 新增建筑开发铁规

新增内容分两步，缺一不可：

**1. `content.js` `BUILD_DEFS` 注册：**

```js
newbuilding: {
  name: '新建筑', icon: '新', desc: '说明',
  baseCost: 300, income: 15, maxLevel: 5,
  w: 96, h: 72, image: 'newbuilding', effect: 'newbuilding'
},
```

**2. `sprites.js` 装配（[sprites.js 顶部铁规](sprites.js)）：**

- `IMG_SRC` → `'assets/newbuilding.png'`
- `ALIGN_KEYS` → 底边贴地
- `MASK_KEYS` → 像素蒙版（建筑专属，遮挡角色）
- `SHADOW_KEYS` → 形状阴影
- `Shadow.config.shrinkX` / `projScale` → 建筑为 `1`

缺任一会在页面顶部红条报错（`validatePipeline` 强制校验）。

贴图规格：透明 PNG / 正方形 / 主体居中 / 底部贴地。用 **AI 抠图 API** 移除背景：
`POST http://192.168.10.10:3366/cutout?format=png&transparent=1`（multipart: image）。

## 🎛️ 透视调整（隐藏控制板）

游戏画布内按 **`~`**（波浪键）显示隐藏控制板：

- **corner（透视夹角）**：建筑底部 V 形夹角，实时在画布生效
- **dy（上下平移）**：整体上下移动
- 每建筑独立保存，`Save` 写入 `kairo_plugin` + 下载 `config.ini`（格式 `建筑key=corner,dy`）

---

## 📌 关于贴图生成

建筑/角色贴图由 **Agnes Image 2.1 Flash** 生成（等距像素/2.5D 风），经抠图 API 转透明 PNG 后接入。批量生成走 `game-sprite-pipeline` skill 的一键脚本。
